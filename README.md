Simple ATM System

A simple console-based ATM system built with Java to practice core Java programming fundamentals.

📌 Project Overview

The Simple ATM System simulates basic ATM operations through a console-based menu.

The user starts with an initial balance of 5000 and can perform different banking operations such as checking the balance, depositing money, withdrawing money, and transferring money.

The project was created as a practical exercise to apply Java fundamentals through a small real-world style application.

⚙️ How It Works

When the program starts, the account balance is set to 5000.

The user is presented with the following menu:

===== ATM =====
1. Check Balance
2. Deposit Money
3. Withdraw Money
4. Transfer Money
0. Exit

Each operation is handled using a separate method.

Check Balance

Displays the user's current account balance.

Deposit Money

Allows the user to enter an amount and adds it to the current balance.

Withdraw Money

Allows the user to withdraw money if the requested amount does not exceed the available balance.

If the withdrawal amount is greater than the balance, the program displays:

Insufficient balance
Transfer Money

Allows the user to transfer an amount from the current balance.

The program checks the available balance before completing the transfer.

Exit

Closes the ATM menu and displays a goodbye message.
